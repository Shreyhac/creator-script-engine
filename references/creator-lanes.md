# Creator Lanes — the roster

One creator, one lane. Two creators running the same format with the same energy
compete with each other and split the learning, so before writing a new template,
check this table and claim an empty lane.

**Keep this file updated.** It is the shared state of the whole system — the one
file in the repo that changes most often, and the reason a new teammate can pick
up a creator without stepping on someone else's format.

## What makes a lane distinct

A lane is the **pair** of format and energy. Either one alone is not enough:

- **Format** = the physical shape. Talking-head, silent reaction, screen-record,
  skit, montage, before/after.
- **Energy** = the emotional posture toward the viewer. Teaching, confiding,
  flexing, warning, reacting, deadpan.

Two creators can share a format if the energy differs sharply — Candace and
Brenda both end on the same product, but one is *"here's the hack, go do it"* and
the other is *"I can't believe this exists."* Those don't cannibalize.

Two creators must **never** share energy on the same format. That's the same
video with a different face.

## Collision test

Before adding a row, run the new format against every existing one:

1. Same format? If no → no collision, done.
2. Same energy? If no → no collision, done.
3. Both the same → **collision.** Change the energy, not the payoff. The payoff
   (what the product does) should be identical across all creators; that's the
   product's story. The route in is what varies.

If you cannot find an open energy for a format, that format is saturated in the
roster. Pick a different format.

---

## Mapping a creator onto the product

Every lane needs a one-line answer to: *why does this format make this product
look good?* If you can't write that line, the pairing is wrong regardless of how
strong the format is.

Worked example:

> **Brenda → static ads.** The "graphic designer who showed me this" hook maps
> perfectly: the reveal is a wall of scroll-stopping ad creatives that look like
> a top designer made them, and the quiet twist is that there was no designer.
> The hook names the person you'd normally have to hire; the payoff is that you
> don't.

Note the structure — the hook names a **cost the viewer currently pays**, and the
reveal removes it. That's a reusable pattern for mapping any format onto any
product, not just this one.

## Adding a creator

1. Decode their references (`template-anatomy.md`).
2. Run the collision test above.
3. Add a row here **before** writing the template, so a teammate starting the
   same day sees the lane is taken.
4. Write the one-line product mapping.
5. Then proceed to `TEMPLATE.md`.

---

## Retiring a lane

When a format stops working, mark the row rather than deleting it — a dead lane
is useful information, and someone will otherwise propose it again in a month.

| Creator | Format | Energy | Lane | CTA |
|---|---|---|---|---|
| ~~Example~~ | ~~format~~ | ~~energy~~ | *retired 2026-01 — CTR fell off after 3 weeks; hooks stopped landing, reveal was fine* | |

Record **which half died** — hooks or reveal. If the reveal is still strong, the
footage is still reusable under a new hook formula.
